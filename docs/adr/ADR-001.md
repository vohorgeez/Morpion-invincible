# ADR-001 : Faire tourner le moteur dans le navigateur, avec un portage en JS

## Contexte
Après la v2, il n'existait qu'une version du morpion sur terminal. L'utilisateur devait identifier la case à jouer par son numéro de 0 à 8, et donc bien visualiser la répartition de ces numéros sur la grille. De plus, exécuter un fichier Python n'est pas à la portée du plus grand nombre, même si notre cas est simple et ne nécessite qu'un seul fichier sans dépendance externe au dépôt.

Une séparation a déjà été opérée à ce stade entre l'affichage (sur terminal) et une API `engine.py`, dans un but avant tout pédagogique, même si cette API peut servir à n'importe quel type d'affichage.

Pour porter le jeu dans un navigateur, qui n'exécute pas de Python, je pouvais :
- envelopper `engine.py` dans un serveur HTTP comme Flask ou FastAPI ;
- faire tourner Python dans le navigateur via Pyodide ou Brython ;
- porter le moteur directement en JavaScript.

## Décision
Je traduis la modélisation du jeu et l'algorithme minimax en JavaScript, et j'abandonne l'utilisation de l'API `engine.py` pour la version web. Un serveur HTTP obligerait à faire tourner Python en permanence quelque part, alors que le portage permet de jouer en ouvrant simplement `index.html`. Le portage est aussi plus simple que de dépendre d'un module externe comme Pyodide ou Brython.

## Statut
Acceptée, le 8 décembre 2025

## Conséquences
Le jeu se joue à la souris, dans une page web. Sans serveur ni module externe, il est autonome : l'utilisateur joue en ouvrant `index.html`, sans rien installer.

Tout vit au même endroit, dans `script.js`. Ce fichier est long et mêle plusieurs responsabilités, ce qui constitue une perte de lisibilité par rapport à la séparation de la v2.

La version Python existe toujours dans le dépôt, mais vit complètement à part. Les tests Python ne concernent donc que la version Python : le moteur réellement utilisé par les joueurs n'est couvert par aucun test, et toute évolution du moteur doit être écrite deux fois. Constat depuis : les améliorations de la v4 (mai 2026) n'existent qu'en Python.
